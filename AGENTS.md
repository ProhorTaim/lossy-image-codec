# Правила проекта

## Что это
Собственный lossy-кодек для изображений с адаптацией под лимит max_bytes.
Участвует в турнире: арена вызывает наш HTTP API для encode/decode закрытого
набора изображений, эксперты слепо голосуют за лучшее визуальное качество.

## Роли и зоны
- Разработчик алгоритма: codec/
- Разработчик ПО: api/, web/
- DevOps: deploy/, .github/
- QA: tests/

## Запрещено (нарушение = дисквалификация или провал)
- Использовать JPEG/WebP/AVIF как единственный формат кодирования.
- Менять размеры изображения при decode (только исходные W×H).
- Отдавать encode больше max_bytes.
- Хранить оригинал на сервере или между запросами (stateless).
- Возвращать redirects (3xx).
- Падать на битых данных — только 4xx с JSON-ошибкой.
- Обходить проверяющую систему (подмена результатов, хранение оригиналов,
  обращение к чужому решению).

## Обязательно
- encode(png_bytes, max_bytes) -> bytes | CannotFit
- decode(fmt_bytes) -> png 8 бит, W×H оригинала, stateless
- GET /v1/health < 3 c, 200 {"status":"ok"}
- Ошибки: {"error":{"code":"...","message":"..."}}
- Время encode/decode: 20 000 мс + 3 000 мс × размер_МБ

## Команды
- make run    # поднять API локально
- make test   # все тесты
- make check  # прогон check-сценария
- make lint   # компиляция/линт

## Workflow
- Ветки по зонам: codec/, api/, deploy/, tests/
- Один PR = одна задача
- main всегда зелёный
- Конфликты в codec/__init__.py, openapi.yaml, AGENTS.md решаются до начала
  работы, а не в мерже
