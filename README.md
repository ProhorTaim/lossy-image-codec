# Perceptual Image Codec

Собственный lossy-кодек для изображений с адаптацией под заданный размер файла.
Разработан для турнира: сохраняет максимальное визуальное качество в рамках
лимита `max_bytes`.

## Что это

Сервис принимает PNG, сжимает в собственный бинарный формат (не JPEG/WebP/AVIF)
и декодирует обратно в PNG тех же размеров. Качество оценивают эксперты
слепым голосованием — не PSNR/SSIM.

## Как запустить локально

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install pytest pillow numpy
make lint
make test
```

Сейчас `make test` запускает smoke-тесты скелета. Реальный кодек и API
появятся по мере готовности.

## Структура

```text
codec/     — формат, энкодер, декодер, rate control
api/       — HTTP по openapi.yaml
web/       — UI: загрузка, max_bytes, слайдер «до/после»
tests/     — тесты кодека и API
deploy/    — Docker, compose, инструкция по туннелю
```

## Контракты

- `openapi.yaml` — HTTP API по спецификации организаторов
- `AGENTS.md` — правила проекта (читать всем)
- `codec/AGENTS.md` — правила для зоны алгоритма
- `codec/__init__.py` — внутренний интерфейс encode/decode

## Проверка

- `make lint` — синтаксис `codec/` и `api/`
- `make test` — тесты (pytest)
- `make check` — сценарий check (пока заглушка)

## Чего НЕ делать

- Использовать готовые кодеки (JPEG/WebP/AVIF) как единственный формат.
- Хранить оригинал на сервере или между запросами.
- Менять размеры изображения при `decode`.
- Обходить проверяющую систему (подмена результата, чужие решения).
